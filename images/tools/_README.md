# Logos de herramientas

Coloca aquí un archivo por logo (preferiblemente SVG o PNG con fondo transparente).
`index.qmd` espera estos nombres:

- excel.svg
- python.svg
- sql.svg
- powerbi.svg
- tableau.svg
- r.svg
- git.svg

Luego, en `index.qmd` (sección Herramientas), reemplaza cada `<span class="tool-placeholder">`
por la línea `<img>` comentada que tiene al lado, en los dos grupos del carrusel.
